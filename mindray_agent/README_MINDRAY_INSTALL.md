# 🚀 Автоматичний експорт аналізів Mindray BS-230 на USB-флешку

Цей пакет призначений для встановлення на **основний комп'ютер біохімічного аналізатора Mindray BS-230**.

---

## ⚡ Як встановити за 10 секунд:

1. Скопіюйте всю папку `mindray_agent` на комп'ютер аналізатора Mindray BS-230 (наприклад, у `D:\Mindray\mindray_agent` або `C:\mindray_agent`).
2. Запустіть файл **`install_autorun.bat`** (подвійним кліком).
3. Готово!

---

## 🔍 Як це працює:

* Скрипт працює абсолютно безшумно у фоновому режимі (без відкритих вікон).
* Автоматично стартує при кожному вмиканні комп'ютера Windows.
* Як тільки лаборант вставляє **будь-яку USB-флешку**:
  1. Агент миттєво зчитує всі свіжі аналізи пацієнтів (глюкоза `Glu`, гамма-ГТ `GGT`, ПІБ, дата, час).
  2. Зберігає на флешці прямо у папку `SCAN_00` легкий файл `SampleInfo_Biochem_YYYY-MM-DD.csv`.
  3. Показує спливаюче сповіщення Windows у правому нижньому кутку:
     *«✅ Аналізи біохімії скопійовано на флешку (SCAN_00)»*.
* Потім цю флешку можна вставити в робочий комп'ютер і просто перетягнути папку `SCAN_00` у **HematoConverter** — програма в 1 клік зчитає і гематологію, і біохімію разом!
