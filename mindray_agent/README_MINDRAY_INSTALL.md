# 🚀 Автоматичний експорт аналізів Mindray BS-230 на USB-флешку

Цей пакет призначений для встановлення на **основний комп'ютер біохімічного аналізатора Mindray BS-230**.

---

## 🚀 Швидкий старт (Встановлення за 10 секунд)

1. Скопіюйте всю папку **`mindray_agent`** на комп'ютер біохімічного аналізатора Mindray (наприклад, у корінь `C:\mindray_agent` або `D:\mindray_agent`).
2. Запустіть файл **`install_autorun.bat`** (подвійним кліком).
3. Готово! Агент автоматично:
   * Зупинить старі процеси та оновить автозапуск Windows (`shell:startup`).
   * Запуститься у тихому фоновому режимі (без чорних вікон, **0% навантаження на процесор**).

---

## 🧪 Миттєва перевірка роботи (Діагностика)

У папці є файл **`test_export_now.bat`**:
* Просто запустіть його подвійним кліком.
* Він відкриє кольорове вікно та покаже повну діагностику в реальному часі:
  1. Знайдену папку Mindray (`OperationSoft`).
  2. Статус підключення до бази даних або файлів друку.
  3. Підключені USB-флешки.
  4. Кількість збережених пацієнтів та шлях до файлу.
* Усі події та помилки також записуються у текстовий файл **`agent_log.txt`**.

---

## 🗑️ Видалення або зупинка

Якщо потрібно зупинити або повністю видалити агента, двічі клікніть **`uninstall.bat`**.

---

## 🔍 Як це працює у щоденній роботі:

1. Скрипт працює абсолютно безшумно у фоні (0% CPU).
2. Як тільки лаборант вставляє **будь-яку USB-флешку**:
   * Агент миттєво зчитує всі свіжі аналізи (глюкоза `Glu`, гамма-ГТ `GGT`, ПІБ, дата, час).
   * Зберігає на флешці прямо у папку `SCAN_00` легкий файл `SampleInfo_Biochem_YYYY-MM-DD.csv`.
   * Показує системне сповіщення Windows: *«✅ Аналізи біохімії скопійовано на флешку (SCAN_00)»*.
3. Потім цю флешку лаборант вставляє у робочий комп'ютер і просто перетягує папку `SCAN_00` у **HematoConverter** — програма автоматично зчитує та об'єднує всі аналізи!
