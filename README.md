# Конвертер результатов анализатора крови в бланки А4 (GitHub Pages)

Веб-приложение для автоматической генерации красивых медицинских бланков общего анализа крови (CBC + 5-DIFF) на листе формата **А4** из экспортированных файлов гематологического анализатора (`SampleInfo_...csv` и папки с графикой `_graphic`).

## ✨ Особенности

- 🔒 **100% Конфиденциальность**: Все данные обрабатываются локально в вашем браузере. Данные пациентов никуда не отправляются.
- 📄 **Формат А4 (1 пациент = 1 страница)**: Идеально скомпонованный медицинский бланк с автопереносом страниц при массовой печати.
- 📊 **Автосопоставление графиков**: Автоматически находит и вставляет в бланк соответствующие гистограммы (WBC, RBC, PLT) и скаттерграмму (DIFF).
- ⚖️ **Автоматическая оценка норм**: Проверяет результаты по референсным интервалам, подсвечивает отклонения (`HIGH ▲` / `LOW ▼`) и выводит системные флаги патологий.
- 🚀 **Работает без сервера**: Можно легко опубликовать на GitHub Pages за 1 минуту.

---

## 🛠️ Как опубликовать на GitHub Pages (Хостинг)

1. Создайте публичный репозиторий на GitHub (например, `blood-analyzer-converter`).
2. Загрузите файлы из этой папки (`index.html`, `style.css`, `app.js`, `README.md`) в созданный репозиторий.
3. Перейдите в настройки репозитория: **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (или `master`) / `(root)`
5. Нажмите **Save**. Через 1–2 минуты ваша ссылка будет готова:  
   `https://<ваш-логин>.github.io/blood-analyzer-converter/`

---

## 📖 Как пользоваться приложениям

1. Откройте ссылку на GitHub Pages.
2. **Шаг 1**: Перетащите файл результатов `SampleInfo_...csv` в первую область загрузки.
3. **Шаг 2**: Выберите папку с графикой `SampleInfo_..._graphic` во второй области загрузки.
4. В левом списке выберите любого пациента для предварительного просмотра.
5. Нажмите **«Печать всех бланков»** для массовой печати или **«Печать текущего бланка»** для одного пациента. В диалоге печати браузера выберите **«Сохранить как PDF»** или ваш принтер.
